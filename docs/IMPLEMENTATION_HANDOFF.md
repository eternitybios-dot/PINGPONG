# 実装担当AIへの引き継ぎ

対象：[eternitybios-dot/PINGPONG](https://github.com/eternitybios-dot/PINGPONG)

## 1. 作るもの

日本語の卓球上達アプリ。イラストでフォームとコツを学び、環境と時間に合った練習を実行し、端末に記録できること。要件は[REQUIREMENTS.md](REQUIREMENTS.md)、教材・練習・図案は[CONTENT_SPEC.md](CONTENT_SPEC.md)を参照する。

現在のリポジトリには既存アプリがない。今回の文書作成ではアプリコードや画像は追加していない。

## 2. 初版の前提

- 提供形態の回答がなければ、Expo / React Native / TypeScriptでiPhone・Androidに対応する案を採用する。
- PWAを希望する回答があれば、ホーム画面追加とオフライン利用を備えたWebアプリへ切り替える。両方を同時に作る必要はない。
- 日本語、初心者〜中級者、シェークハンド、右利き／左利きに対応。
- 登録なし、端末内保存、通信なしで主要機能を使用できる構成。
- 初版は静止画で学習が完結する。フォーム撮影・AI分析・クラウド同期は将来スコープ。

## 3. 実装順序

| 段階 | 完成させるもの | 確認すること |
| --- | --- | --- |
| 1 | プロジェクト、4つのタブ、設定、保存の基盤 | 開発用ビルドで起動でき、設定が再起動後も残る |
| 2 | 16教材・24練習・イラストのデータと一覧・詳細 | リンク、検索、図の拡大、左右、必須データの整合 |
| 3 | 時間と環境からのメニュー、入れ替え、確認画面 | 条件不一致を排除し、全バリエーションの時間合計が正しい |
| 4 | タイマー、休憩、スキップ、中断状態、振り返り、履歴 | 停止中の時間を足さず、二重保存せず、途中記録を復元できる |
| 5 | オフライン、空状態、保存失敗、文字拡大・読み上げ、最終調整 | AC01〜AC16を確認し、未対応事項を明記する |

P0の完成後にP1を検討する。将来機能のためのバックエンドやログインを初版に先行導入しない。

## 4. 実装時の注意

- 原稿を構造化データにし、教材ID・練習IDを固定する。UI文言と教材の本文を別々に管理できるようにする。
- CONTENT_SPECのカタログはタイトルと原稿案。全教材・練習について詳細原稿と図を仕上げる。
- 画像はアプリ内に含め、外部URLと通信を教材閲覧の前提にしない。
- テキストや番号を含む画像全体を反転しない。球の回転図と左右表現を確認する。
- 記録はユーザーが実施した分だけ。成功率、成長率、連続利用日をダミー表示しない。
- 保存成功後に成功表示を出す。途中状態・通常の履歴に一意なセッションIDを使う。
- タイマーの描画周期だけで時間を積算せず、実際の経過と停止状態を管理する。
- 原稿のサービス規則はITTF公式の現行資料で確認し、確認日を残す。
- 新たなライブラリを選ぶ際は現在の安定版と採用理由をREADMEに記載する。

## 5. 納品物と検証

納品物：

1. 起動・ビルドできるアプリコード。
2. 16教材・24練習・7テンプレートと60分派生メニューの構造化データ。
3. 最低88枠の学習用イラストと、必要な左右差分・説明・権利情報。
4. インストール、開発、ビルド、動作確認の手順を記載したREADME。
5. 受入条件AC01〜AC16の実施結果と、残っている課題。

検証は、メニュー条件・時間合計、タイマー状態と経過時間、記録の集計と二重保存防止など、誤ると体験が壊れるロジックを中心にする。画面・図・左右・機内モード・バックグラウンド復帰・文字拡大は、シミュレーターまたは実機で確認する。実際に確認していない環境は確認済みと記載しない。
