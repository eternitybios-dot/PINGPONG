# 実装担当AIへの引き継ぎ

対象：[eternitybios-dot/PINGPONG](https://github.com/eternitybios-dot/PINGPONG)

## 1. 作るもの

日本語の卓球上達ブラウザアプリ（PWA）。スマホのURLから利用でき、イラストでフォームとコツを学び、環境と時間に合った練習を実行し、ブラウザ内に記録できること。要件は[REQUIREMENTS.md](REQUIREMENTS.md)、教材・練習・図案は[CONTENT_SPEC.md](CONTENT_SPEC.md)を参照する。

現在のリポジトリには既存アプリがない。今回の文書作成ではアプリコードや画像は追加していない。

## 2. 初版の前提

- 提供形態はユーザー指定でブラウザ版に確定。スマホ優先のPWAを作り、ホーム画面追加とオフライン利用に対応する。
- 技術候補はReact / TypeScript / Vite。静的配信できる構成にし、本番配信はHTTPSを前提とする。
- 日本語、初心者〜中級者、シェークハンド、右利き／左利きに対応。
- 登録なし、ブラウザ内保存。初回オンライン読み込みと教材の保存完了後、通信なしで主要機能を使用できる構成。
- 初版は静止画で学習が完結する。フォーム撮影・AI分析・クラウド同期は将来スコープ。

## 3. 実装順序

| 段階 | 完成させるもの | 確認すること |
| --- | --- | --- |
| 1 | Webプロジェクト、4つのタブ、URL、設定、ブラウザ内保存の基盤 | URLから開け、直接アクセス・再読み込み・戻るが動作し、設定が再起動後も残る |
| 2 | 16教材・24練習・イラストのデータと一覧・詳細 | リンク、検索、図の拡大、左右、必須データの整合 |
| 3 | 時間と環境からのメニュー、入れ替え、確認画面 | 条件不一致を排除し、全バリエーションの時間合計が正しい |
| 4 | タイマー、休憩、スキップ、中断状態、振り返り、履歴 | 停止中の時間を足さず、二重保存せず、途中記録を復元できる |
| 5 | Manifest、ホーム画面追加、オフライン保存と更新、空状態、保存失敗、文字拡大・読み上げ | AC01〜AC18を確認し、未対応事項を明記する |

P0の完成後にP1を検討する。将来機能のためのバックエンドやログインを初版に先行導入しない。

## 4. 実装時の注意

- 原稿を構造化データにし、教材ID・練習IDを固定する。UI文言と教材の本文を別々に管理できるようにする。
- CONTENT_SPECのカタログはタイトルと原稿案。全教材・練習について詳細原稿と図を仕上げる。
- 画像・教材・画面を同じWebアプリの配信資産として用意し、Service Workerで保存する。オフライン準備の進捗・失敗・完了を表示する。
- 教材キャッシュとIndexedDB等のユーザー記録を分け、アプリ更新で記録を削除しない。練習中に更新のため再読み込みしない。
- Web App Manifestとアイコンを用意し、iPhone SafariとAndroid Chromeのホーム画面追加を案内する。
- テキストや番号を含む画像全体を反転しない。球の回転図と左右表現を確認する。
- 記録はユーザーが実施した分だけ。成功率、成長率、連続利用日をダミー表示しない。
- 保存成功後に成功表示を出す。途中状態・通常の履歴に一意なセッションIDを使う。
- タイマーの描画周期だけで時間を積算せず、実際の経過と停止状態を管理する。
- ページが非表示になったら停止し、再読み込み・復帰後に本人の操作で再開する。複数タブで同じセッションを同時に動かさない。
- 原稿のサービス規則はITTF公式の現行資料で確認し、確認日を残す。
- 新たなライブラリを選ぶ際は現在の安定版と採用理由をREADMEに記載する。

## 5. 納品物と検証

納品物：

1. ローカル起動・本番用ビルドができるWebアプリコード、Web App Manifest、Service Worker、アイコン。
2. 16教材・24練習・7テンプレートと60分派生メニューの構造化データ。
3. 最低88枠の学習用イラストと、必要な左右差分・説明・権利情報。
4. 開発、ビルド、HTTPS配信、ホーム画面追加、オフライン利用、対応ブラウザの手順を記載したREADME。
5. 受入条件AC01〜AC18の実施結果と、残っている課題。

検証は、メニュー条件・時間合計、タイマー状態と経過時間、記録の集計と二重保存防止など、誤ると体験が壊れるロジックを中心にする。画面・図・左右・機内モードでの再読み込み・別タブからの復帰・文字拡大・ホーム画面追加は、対応ブラウザと実機で確認する。実際に確認していない環境は確認済みと記載しない。
