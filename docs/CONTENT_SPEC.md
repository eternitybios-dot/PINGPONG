# PINGPONG 教材・練習・イラスト仕様

版：1.1 / 2026-10-02 / [要件定義書](REQUIREMENTS.md)に従う。提供形態はスマホ優先のブラウザアプリ（PWA）。

この文書は実装担当AIへの教材原稿案と制作指示。完成イラストやアプリ実装は含まない。初版はシェークハンド・右利き／左利きを対象にする。

## 1. 教材の共通テンプレート

各教材に次の項目をそろえる。

1. 目的：「どの場面で役立つか」を1文で示す。
2. 要点：最初に覚えることを3つ以内。
3. フォーム全体図：足、体、ラケット、球を必要に応じて表示。
4. 3〜4段階の連続図と短い説明。
5. NG/OK比較：間違いと修正を1組以上。
6. 補助図：ラケット面、回転、軌道、足位置などを拡大。
7. セルフチェック：自分で確認できる2〜3項目。
8. 関連練習：1〜3種目へのリンク。

「腰を使う」など抽象的な一言だけで終えず、何をどう動かすかを図と説明で対応させる。特定の角度やタイミングを全ての球に当てはめない。

### 原稿の完成例：T04 フォアハンドの基本打ち

目的：フォア側のラリーを、無理のないフォームで続ける。

最初に意識すること：

- 球に合わせて足を動かし、体の前に打つ空間を作る。
- 腕だけで大きく振らず、足腰・体の向きと腕の動きをつなげる。
- 打った後は、次の球を迎える構えへ戻る。

右利きの段階図の指示：

| 段階 | 説明 | 描く内容 |
| --- | --- | --- |
| 1 構え | 膝と股関節を軽く曲げ、ラケットを体の前に置く | 足元まで見える全身、視線、台との位置 |
| 2 準備 | 球の位置に合わせて移動し、体を少しひねって準備する | 移動の足跡、体の向き、引いたラケット |
| 3 打球 | 体の前で球をとらえ、体の動きとともに前へ振る | 接触点、球の入口と出口、ラケットの方向 |
| 4 戻り | 振り終えたらラケットと体を構えへ戻す | 戻りの矢印、次の球を待つ姿勢 |

NG/OK：球が体に近すぎて肘が窮屈になる例と、足で距離を調整して前に空間を作る例。補助図は打球位置とラケット面を側面から示す。面の角度は球の高さ・回転で変わる注記を添える。

セルフチェック：「球に合わせて足を動かせたか」「体の前で打てたか」「次の構えへ戻れたか」。関連練習はD02、D07、D10。

### サーブ教材の確認事項

- 静止したフリーハンドの開いた手のひらから始める。
- 球をほぼ垂直に16cm以上投げ上げ、投げ上げで回転をかけず、下降してくる球を打つ。
- サーブ開始から打球まで、球は台面より上・エンドラインより後ろにあり、相手から隠さない。
- まず自分のコート、次に相手のコートへバウンドすることを図示する。

### 各練習で仕上げる情報

- 目的、場所・用具、ウォームアップ後に行うこと。
- 手順を3〜5ステップ。相手が行うことも明記。
- セット数・実施秒数・セット間休憩。合計が標準枠を超えないようにする。
- 今日意識する点を1つ。図のどこを見るかを添える。
- 達成指標の種類：連続回数／目標到達数・試行数／自己チェック／測定なし。
- 易しくする方法：速度を下げる、目標ゾーンを広げる、移動幅を小さくする等。
- 難しくする方法：速度を少し上げる、目標ゾーンを狭める、球の種類を増やす等。
- 痛みや床面の滑りなど、その練習に関係する注意を短く添える。
- 個別の練習配置図と関連教材。

### 詳細の完成例：D02 フォアのシャドー（3分）

条件：1人、台なし。ラケットは任意。腕を振っても周りにぶつからない場所。

| 区間 | 時間 | 内容 |
| --- | --- | --- |
| 準備 | 20秒 | 足元と周囲を確認し、T04の構えを作る |
| セット1 | 40秒 | ゆっくりフォアの動きを反復する |
| 休憩 | 20秒 | 力を抜き、打点と構えを確認する |
| セット2 | 40秒 | 振る前に球の位置を想像する |
| 休憩 | 20秒 | 肩・腕に無理な力が入っていないか確認する |
| セット3 | 40秒 | 打った後に構えへ戻るところまで反復する |

合計180秒。「毎回構えへ戻れた」をセルフチェックする。速さは競わない。易しくする場合は動きを小さくし、難しくする場合は小さな左右移動を加える。痛みが出る動きは止める。

### 詳細の完成例：D07 フォアの安定ラリー（5分）

準備30秒、ラリー60秒×3セット、セット間休憩30秒×2回、振り返り30秒＝300秒。相手はフォアのクロスへ、続けやすい速さで返す。連続10球を2回目安にし、本人が最大連続回数を入力できる。毎回打球後に構えへ戻る。易しくする場合は速さを下げ、難しくする場合は目標ゾーンを少し狭める。

### 詳細の完成例：D15 下回転サーブの目標打ち（5分）

準備・ルール確認30秒、サーブ45秒×4セット、球拾い・休憩30秒×3回＝300秒。広い目標ゾーンを設け、各セットで合法なサーブと低い軌道を優先する。記録したい場合は10球を測定区間にして、目標ゾーン到達数を入力する。目標へ入っただけで回転量が正しいと判定しない。

準備は周囲・道具の確認と無理のない動的な体操、整理は呼吸を落ち着ける軽い運動と振り返り。負荷の高い筋力トレーニングや痛みを我慢するストレッチを要求しない。

休憩はまとめて末尾に置かず、種目間に配分する。台あり60分の1人練習では球拾い・給水を十分に含め、連続してサーブを打ち続けさせない。P01〜P02で球・ラケットを持っていない場合、D01・D06は道具不要のD02・D03へ置換し、合計時間が一致するよう休憩を調整する。

### 推薦と入れ替えの決め方

1. 台・相手・道具の条件で実行可能な種目を絞る。
2. 本人のレベルで絞る。発展種目を初心者へ自動推薦しない。
3. 選択時間と環境に合うテンプレートを選ぶ。
4. 目的に合う候補、前回の課題、本人が選んだお気に入りを優先して種目を置き換える。
5. 準備・整理時間を残し、選択時間を超えないように休憩を含めて合計を再計算する。
6. 適合する目的別種目がない場合は、基本メニューを提示して「台なしでできる基本練習」など理由を示す。

「台あり60分」など同じ条件のメニューでも、残り時間が不足した種目を無理に押し込まない。開始前に全内容を確認できるようにする。

## 5. イラスト制作の共通仕様

### 5.1 図の形式と描き方

- 明るい背景、単純な線、必要な部分にアクセントを使う。体型・服装・線の太さ・台の形を統一する。
- 全身図では足を切らず、動きに必要な余白を残す。打点の説明には側面または斜めの視点、足運び・コースには俯瞰を使う。
- 球の軌道は実線、体・ラケットの動きは破線、回転は球の周りの円弧など、種類を分けて凡例を添える。
- 球の入口→接触→出口が分かるようにし、球の軌道とラケットの矢印を混同させない。
- 接触点は丸囲み、足位置は足跡、順序は1〜4の番号で表す。色だけで情報を伝えない。
- NG/OKは同じ視点・サイズ・局面を使う。間違いを大げさな人体の崩れで示さず、直すポイントを1つに絞る。
- 背景の観客・装飾・長い文章を省き、体・ラケット・球・台を見やすくする。
- 回転の模式図には「模式図」と表示し、図の視点を明記する。

### 5.2 左右対応

- 右利き・左利きを各図の表示で区別する。
- 足位置、ラケットを持つ手、フォーム、クロス／ストレートの説明をまとめて変換する。
- 日本語、番号、凡例、UIは反転しない。可能なら人物・図形と文字を分けた素材で管理する。
- 回転の向きと図の視点を確認する。単に全画像を左右反転して正しいと扱わず、球の回転を含む図を個別に確認する。
- 左右に関係しない握りの説明・ルール図などは共有してよい。ユーザーの選択と食い違う体の図を残さない。

### 5.3 ファイル・説明情報

推奨する素材の管理例：

- `T04-overview-right.svg` / `T04-overview-left.svg`
- `T04-sequence-right.svg` / `T04-sequence-left.svg`
- `T04-comparison-right.svg` / `T04-comparison-left.svg`
- `T04-contact-right.svg` / `T04-contact-left.svg`
- `D07-layout.svg`（左右差がある場合は各利き手用を用意）

名前は例であり、実装方式に合わせて変更できる。論理IDと教材との対応表は保持する。SVG内部の文字または別のUIラベルに日本語を使い、拡大時にもぼやけない形式にする。

各図には「何を伝えるか」「視点」「対応する段階」「利き手」「説明文」「代替テキスト」「権利情報」を持たせる。例：T04打球図の代替テキストは「右利きの選手が、足で球との距離を調整し、体の前でフォアハンドを打つ。球の入口と返球方向を矢印で示す」。

### 5.4 完成前の確認

1. 学習の目的が1つの枠から読み取れる。
2. 姿勢・腕・指・ラケット・台・球が不自然に接続していない。
3. 文章の段階と図の順番・打点・矢印が一致する。
4. 正しい例がNG例と明確に違い、修正点を説明できる。
5. 日本語と番号が正しく、スマホ表示と拡大表示で読める。
6. 左用でも文字が反転せず、フォームと左右表現が合う。
7. サーブのトス・球の位置・見え方・バウンドが公式ルールに沿う。
8. 図がない場合も文章と代替テキストで要点を理解できる。

卓球指導者の確認は品質向上のために推奨する。制作段階で疑問のあるフォームは断定したまま掲載せず、説明と図を修正する。
